Git Workflow Assignment - Command Log

1. git init -b main
   Creates a local Git repository with the main branch.

2. git add index.html about.html
   Stages the initial HTML pages for the first commit.

3. git commit -m "Add initial HTML project pages"
   Records the initial project state in the repository history.

4. git add index.html
   Stages the edited home page.

5. git commit -m "Describe workflow demonstration"
   Records the second change on main.

6. git branch feature
   Creates the feature branch from the current main commit.

7. git switch feature
   Switches the working branch to feature.

8. git add about.html
   Stages the feature-branch change to the about page.

9. git commit -m "Add feature workflow details"
   Records the feature work on the feature branch.

10. git switch main
    Returns to main before integrating the feature.

11. git merge --no-ff feature -m "Merge feature branch"
    Merges feature into main and creates a merge commit.

12. git log --all
    Displays commit history from all branches.

13. git add .gitignore git_commands.txt
    Stages the ignore rules and command documentation.

14. git commit -m "Ignore log files and temp directory"
    Records the .gitignore configuration.

15. git add undo-demo.txt
    Stages a temporary file used to demonstrate undoing a commit.

16. git commit -m "Add temporary undo demonstration file"
    Creates the additional commit that will be undone.

17. git revert --no-edit HEAD
    Undoes the last commit by creating a revert commit.

18. git status
    Shows the current branch and whether any changes remain.

19. git check-ignore scratch.log temp/sample.txt
    Confirms that a .log file and a file inside temp/ are ignored by Git.

20. git remote -v
    Shows the connected GitHub repository URL.

21. git push -u origin main
    Pushes main to GitHub and sets its upstream branch.
